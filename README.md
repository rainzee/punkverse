# Punk Forge

CryptoPunks 风格的 24×24 像素头像生成器，所有像素都由程序生成（没有使用原版素材），支持 18 种渲染风格。

```bash
bun install
bun run dev        # 开发服务器 http://localhost:3000
bun run build      # 输出到 dist/
bun run preview abc --head=cap --kind=female   # 在终端里预览
```

## 功能

- **按种子生成**：同一个种子加上同样的设置，永远得到同一个头像；地址栏的 hash 里保存了全部状态，可以直接分享
- **类型**：男 / 女 / 僵尸 / 猿 / 外星人，人类有 4 种肤色
- **属性**：头部 28 种、眼部 13 种、胡须 10 种、嘴部 9 种、配饰 7 种，多数还有多种配色。每个部位都可以设为随机、无或者锁定成某一个；锁定一个部位不会改变其它部位的随机结果
- **风格**：经典、霓虹、Game Boy、1-bit 抖动、马卡龙、负片、蓝图、蒸汽波、LED 点阵、黄金雕像、故障、体素 3D、终端、积木、热成像、旧照片、波普网点、墨水
- **导出**：PNG（24 到 2048 px）、SVG、JSON 元数据
- **快捷键**：`空格` 随机一个，`← →` 切换风格

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/punk.ts` | 男女基础头型、种族与肤色、确定性生成 |
| `src/traits.ts` | 所有部件，按锚点绘制，同一套代码适配男女两种头型 |
| `src/styles.ts` | 风格定义：背景、逐像素调色、像素形状、后期效果 |
| `src/render.ts` | 渲染管线，同时输出到 Canvas 和 SVG |
| `src/painter.ts` | Canvas / SVG 两个绘图后端 |

要加新风格，往 `STYLES` 里追加一项；要加新部件，往 `traits.ts` 对应的数组里追加一个 `t({...})`。
