# Punk Forge

CryptoPunks 风格的 24×24 像素头像生成器，所有像素都由程序生成（没有使用原版素材），支持 21 种渲染风格。

```bash
bun install
bun run dev        # 开发服务器 http://localhost:3000
bun run build      # 输出到 dist/
bun run preview abc --head=cap --kind=female   # 在终端里预览
```

## 功能

- **按种子生成**：同一个种子加上同样的设置，永远得到同一个头像；地址栏的 hash 里保存了全部状态，可以直接分享
- **主题**：经典 / 银翼杀手 / 西部世界 / 绝命毒师。主题和种族是两回事：主题决定出现哪些种族、哪些部件（含主题专属部件，比如霓虹伞、复制人瞳光、宽檐牛仔帽、机体外露、海森堡帽、黄色防护服）、部件出现的概率和配色，并会切换到对应的默认风格
- **类型**：男 / 女 / 僵尸 / 猿 / 外星人 / 机器人 / 骷髅 / 恶魔，每种都有多种肤色（人类 6 种）
- **属性**：头部 45、眼部 22、胡须 15、嘴部 17、衣着 9、配饰 15，共 123 种，多数带多种配色，另有约 10% 概率随机生成“异色”配色。每个部位都可以设为随机、无或锁定；锁定一个部位不会改变其它部位的随机结果
- **五官变体**：眉形、眼型、鼻型、嘴型、皱纹 / 眼袋随机组合，同样的属性也会长出不同的脸
- **风格**：经典、霓虹、Game Boy、1-bit 抖动、马卡龙、负片、蓝图、蒸汽波、LED 点阵、黄金雕像、故障、体素 3D、终端、积木、热成像、旧照片、波普网点、墨水、雨夜霓虹、通缉令、沙漠滤镜
- **导出**：PNG（24 到 2048 px）、SVG、JSON 元数据
- **快捷键**：`空格` 随机一个，`← →` 切换风格

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/punk.ts` | 男女基础头型、种族与肤色、确定性生成 |
| `src/traits/` | 所有部件，按锚点绘制，同一套代码适配男女两种头型 |
| `src/themes.ts` | 主题：种族分布、部件禁用与加权、主题配色、默认风格 |
| `src/features.ts` | 五官变体与非人类种族的面部改造 |
| `src/styles.ts` | 风格定义：背景、逐像素调色、像素形状、后期效果 |
| `src/render.ts` | 渲染管线，同时输出到 Canvas 和 SVG |
| `src/painter.ts` | Canvas / SVG 两个绘图后端 |

要加新风格，往 `STYLES` 里追加一项；要加新主题，在 `themes.ts` 里定义一个 `theme({...})`，专属部件写在 `src/traits/theme-*.ts` 并标上 `theme`；要加新部件，往 `src/traits/` 下对应的数组里追加一个 `t({...})`。
