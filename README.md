# Punk Forge

CryptoPunks 风格的 24×24 像素头像生成器，所有像素都由程序生成（没有使用原版素材）。

```bash
bun install
bun run dev        # 开发服务器 http://localhost:3000
bun run build      # 输出到 dist/
bun run preview abc --world=westworld --sex=female --species=robot --head=cap   # 在终端里预览
```

## 术语

项目里（界面、代码、文档）统一使用下面这些叫法。

| 叫法 | 代码 | 含义 |
| --- | --- | --- |
| 世界 | `world` | 头像所处的设定：经典、银翼杀手、西部世界、绝命毒师。决定随机时的性别与物种分布、可用的部件、部件出现的概率和配色，以及默认风格 |
| 性别 | `sex` | 男 / 女。决定基础头型，以及只限某一性别的部件 |
| 物种 | `species` | 人类、僵尸、猿、外星人、机器人、骷髅、恶魔。决定肤色和面部改造 |
| 肤色 | `skin` | 物种下的具体调色板 |
| 部位 | `slot` | 头部、眼部、胡须、嘴部、衣着、配饰 |
| 部件 | `trait` | 某个部位上的具体物件，比如棒球帽、经典墨镜 |
| 专属部件 | `trait.world` | 只在某个世界出现的部件 |
| 配色 | `swatch` | 部件的颜色方案 |
| 五官 | `face` | 眉形、眼型、鼻型、嘴型、皱纹，与部件无关的随机脸部变化 |
| 风格 | `style` | 渲染方式，与生成结果无关 |

世界、性别、物种三者相互独立，可以任意组合，比如西部世界里的女骷髅。

## 功能

- **按种子生成**：同一个种子加上同样的设置，永远得到同一个头像；地址栏里保存了全部状态，可以直接分享
- **世界**：4 个，共 33 个专属部件，比如霓虹伞、复制人瞳光、宽檐牛仔帽、机体外露、海森堡帽、黄色防护服
- **性别**：2 种
- **物种**：7 种，每种都有多种肤色（人类 6 种）
- **部件**：头部 53、眼部 26、胡须 16、嘴部 21、衣着 20、配饰 20，共 156 个，多数带多种配色；经典世界里还有约 10% 概率出现随机的“异色”。每个部位都可以设为随机、无或锁定，锁定一个部位不会改变其它部位的随机结果；点预览旁的性别、物种或部件也能锁定
- **五官**：同样的部件也会长出不同的脸
- **风格**：21 种，经典、霓虹、Game Boy、1-bit 抖动、马卡龙、负片、蓝图、蒸汽波、LED 点阵、黄金雕像、故障、体素 3D、终端、积木、热成像、旧照片、波普网点、墨水、雨夜霓虹、沙漠滤镜、通缉令
- **导出**：PNG（24 到 2048 px）、SVG、JSON
- **快捷键**：`空格` 随机一个，`← →` 切换风格

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/worlds.ts` | 世界：性别与物种分布、禁用与加权的部件、配色、默认风格 |
| `src/species.ts` | 物种与肤色、性别列表 |
| `src/punk.ts` | 男女基础头型、确定性生成、栅格化 |
| `src/features.ts` | 五官变化与非人类物种的面部改造 |
| `src/traits/` | 所有部件，按锚点绘制，同一套代码适配男女两种头型；`world-*.ts` 是各世界的专属部件 |
| `src/styles.ts` | 风格：背景、逐像素调色、像素形状、后期效果 |
| `src/render.ts` | 渲染管线，同时输出到 Canvas 和 SVG |
| `src/painter.ts` | Canvas / SVG 两个绘图后端 |

- 新风格：往 `STYLES` 里追加一项
- 新世界：在 `worlds.ts` 里定义一个 `world({...})`，专属部件写在 `src/traits/world-*.ts` 并标上 `world`
- 新部件：往 `src/traits/` 下对应的数组里追加一个 `t({...})`
- 新物种：在 `species.ts` 里追加，并在 `features.ts` 里写它的面部改造
